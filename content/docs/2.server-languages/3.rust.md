Rust is renowned for its speed, memory safety, and uncompromising compiler-level guarantees. The Arri Rust server library (currently in active development) leverages Rust's type system and macros to create compile-safe, high-performance RPC servers.

> **Note**: Rust server support is currently in-progress and experimental. Features, API shapes, and macro definitions may undergo substantial changes.

---

## Installation

Once released, you can add the Arri Rust server package to your `Cargo.toml`:

```toml
[dependencies]
arri_server = "0.1.0"
serde = { version = "1.0", features = ["derive"] }
```

During the active development phase, it can be referenced directly from the main repository:

```toml
[dependencies]
arri_server = { git = "https://github.com/modii-dev/arri.git", branch = "main" }
serde = { version = "1.0", features = ["derive"] }
```

## Setup and Server Initialization

An Arri server in Rust is built around the `ArriApp` structure.

To construct the API boundary, all RPC input and output models must derive `#[derive(ArriModel)]`. This macro automatically implements serialization, deserialization, and provides the necessary metadata to convert the structs into Arri Type Definitions (ATD).

```rust
use arri_server::prelude::*;
use serde::{Deserialize, Serialize};

// 1. Define Request/Response models using #[derive(ArriModel)]
#[derive(Serialize, Deserialize, ArriModel, Clone)]
pub struct SayHelloInput {
    pub name: String,
}

#[derive(Serialize, Deserialize, ArriModel, Clone)]
pub struct SayHelloOutput {
    pub message: String,
}

// 2. Define the RPC handler using the #[rpc] attribute macro
#[rpc(method = "post", path = "/say-hello")]
async fn say_hello(input: SayHelloInput) -> Result<SayHelloOutput, ArriError> {
    if input.name.is_empty() {
        return Err(ArriError::new(400, "Name must not be empty"));
    }

    Ok(SayHelloOutput {
        message: format!("Hello {}!", input.name),
    })
}

#[tokio::main]
async fn main() {
    // 3. Initialize the Arri App
    let mut app = ArriApp::new();

    // 4. Register the handler procedure
    app.register(say_hello);

    // 5. Start the high-performance HTTP server
    app.start("127.0.0.1:3000").await.unwrap();
}
```

## How schemas are generated in Rust

Unlike languages that rely on runtime reflection, Arri's Rust implementation is entirely **compile-time safe**:

- The `#[derive(ArriModel)]` macro parses the Rust struct definitions during compilation and generates static methods returning their JSON Type Definition (JTD) schemas.
- When the server boots, `ArriApp` calls these static schema generation methods to instantly assemble the **Arri App Definition (AAD)** file.
- Because everything is resolved at compile-time/boot-time, request handling has **absolute zero overhead** and operates at the speed of native compiled JSON parsing, with no runtime reflection or intermediate spec interpretation.

## Errors and Status Codes

To return errors in Rust handlers, use the `ArriError` type, which translates directly to standard Arri HTTP Error Responses:

```rust
#[rpc(method = "post", path = "/delete-post")]
async fn delete_post(input: DeletePostParams) -> Result<DeletePostResponse, ArriError> {
    let authorized = check_auth(&input.token);
    if !authorized {
        return Err(ArriError::new(401, "Unauthorized access to resource"));
    }

    // ... logic ...
    Ok(DeletePostResponse { success: true })
}
```

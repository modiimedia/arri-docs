Go is an excellent choice for building high-performance, microsecond-latency APIs. Arri supports Go servers natively, allowing you to use standard Go structs as your API boundaries.

> **Note**: Go server support is in an active early release stage. Expect minor API shifts as it matures to v1.0.

---

## Installation

Add the Arri Go packages to your project:

```bash
go get github.com/modii-dev/arri/languages/go/go-server
```

---

## Setup and Server Initialization

An Arri server in Go is initialized using the `arri.NewApp()` function. Go structures define the endpoints' arguments and return shapes using standard struct tags (specifically `json` or `arri` tags for validation).

```go
package main

import (
    "github.com/modii-dev/arri/languages/go/go-server"
)

// Define request/response shapes
type SayHelloInput struct {
    Name string `json:"name"`
}

type SayHelloOutput struct {
    Message string `json:"message"`
}

func main() {
    // 1. Initialize the App
    app := arri.NewApp[any]()

    // 2. Register RPC procedure
    arri.Rpc(&app, SayHello, arri.RpcOptions{})

    // 3. Start Server
    app.Start()
}

// 3. Handler function matching Arri's Go Signature
func SayHello(
    input SayHelloInput,
    req arri.Request[any],
) (SayHelloOutput, arri.RpcError) {
    if input.Name == "" {
        return SayHelloOutput{}, arri.NewError(400, "Name must not be empty")
    }

    return SayHelloOutput{
        Message: "Hello " + input.Name + "!",
    }, nil
}
```

---

## How schemas are generated in Go

Behind the scenes, when you register a handler function using `arri.Rpc()`, Arri employs Go's powerful reflection (`reflect`) library. It inspects the input and output structural parameters to infer their property names and types.

This reflection occurs strictly once at server startup to construct the JSON App Definition. Consequently, there is **zero runtime overhead** during standard request processing; it is as fast as Go's native JSON encoders.

## Routing and Groups

You can group procedures together to form sub-paths or organize your larger projects:

```go
userGroup := arri.Group(&app, "/users")

// Registering to group creates '/users/get-profile' route
arri.Rpc(userGroup, GetProfile, arri.RpcOptions{})
```

TypeScript has first-class, premier support within the Arri ecosystem. Using the `@arrirpc/server` framework, you can build modular, fully typed endpoints with automatic schema compilation.

---

## Installation

Add the core TypeScript server and schema packages to your project:

```bash
pnpm add @arrirpc/server @arrirpc/schema
```

---

## Creating the App

Your server is initialized using the `ArriApp` class. This handles routing, request life cycles, middleware, and generates the App Definition.

```typescript
import { ArriApp } from '@arrirpc/server';

const app = new ArriApp({
    rpcRoutePrefix: 'rpcs', // Optional: customize the route prefix
});
```

---

## Defining Endpoints

Endpoints are registered with the `app.rpc()` or `app.defineRpc()` helper. You must supply:
1.  **input**: A schema built using `@arrirpc/schema` (the parameters payload). Pass `undefined` if there are no parameters.
2.  **output**: A schema for the return payload. Pass `undefined` if there is no response.
3.  **handler**: The asynchronous function executing the request.

```typescript
import { ArriApp, defineRpc } from '@arrirpc/server';
import { a } from '@arrirpc/schema';

const app = new ArriApp();

// Define validation schemas
const PostItemParams = a.object('PostItemParams', {
    title: a.string(),
    content: a.string(),
});

const PostItemResponse = a.object('PostItemResponse', {
    id: a.string(),
    success: a.boolean(),
});

// Register the RPC
app.rpc('createPost', defineRpc({
    input: PostItemParams,
    output: PostItemResponse,
    async handler({ input, event }) {
        // 'input' is fully typed based on PostItemParams!
        console.log(`Creating post with title: ${input.title}`);
        
        return {
            id: 'post_123',
            success: true,
        };
    }
}));
```

## Streaming Endpoints (SSE)

To define a server-sent streaming endpoint, set `transport: "sse"`. Handlers for SSE RPCs are passed an `event` context where you can push items asynchronously.

```typescript
import { a } from '@arrirpc/schema';
import { defineSseRpc } from '@arrirpc/server';

app.rpc('watchMessages', defineSseRpc({
    input: a.object('WatchMessagesParams', {
        channelId: a.string(),
    }),
    output: a.object('MessagePayload', {
        text: a.string(),
        sender: a.string(),
    }),
    async handler({ input, stream }) {
        // Push initial data
        stream.push({ text: 'Connected!', sender: 'System' });

        // Push data on an interval
        const interval = setInterval(() => {
            stream.push({
                text: 'New automated message',
                sender: 'Bot',
            });
        }, 5000);

        // Handle disconnect cleanup
        stream.onClosed(() => {
            clearInterval(interval);
        });
    }
}));
```

## Middleware and Context

Arri apps support global middleware or route-specific middleware. You can use them to parse authentication headers, inject database connections, and populate context.

```typescript
app.use((event) => {
    // Inject a db client or custom object into event context
    event.context.db = myDatabaseClient;
});
```

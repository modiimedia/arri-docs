To begin using Arri, you'll need to set up the Arri CLI in your project. The CLI is responsible for running development servers, listening to schema modifications, and compiling client libraries.

---

## Prerequisites

- **Node.js**: Version 18.x or higher is required to run the CLI.
- **Package Manager**: `npm`, `pnpm`, or `yarn`.

---

## Initializing a New Project

The easiest way to start is to use our interactive initializer template. Run the following command in your terminal:

```bash
npx arri init my-arri-app
```

This interactive CLI will walk you through setting up a workspace. You can choose:

1.  **TypeScript Server**: A fast template using `@arrirpc/server` and `@arrirpc/schema`.
2.  **Go Server**: A lightweight Go server using `go-server` packages.

---

## Manual Installation

If you want to add Arri RPC to an existing project, install the `arri` dependency as a development tool:

```bash
# Using npm
npm install -D arri

# Using pnpm
pnpm install -D arri
```

### Create the Arri Config

Arri is configured via an `arri.config.ts` (or `.js`) file at the root of your project workspace. This file registers which language client generators to trigger when schemas change.

Create an `arri.config.ts` file:

```typescript
import { defineConfig, generators } from 'arri';

export default defineConfig({
    // Tell Arri where your server entrypoint is
    entry: './src/index.ts',

    // Register clients you want to generate
    generators: [
        generators.typescriptClient({
            clientName: 'MyApiClient',
            outputFile: '../frontend/src/generated-client.ts',
        }),
        generators.dartClient({
            clientName: 'MyApiClient',
            outputFile: '../mobile/lib/generated_client.dart',
        }),
    ],
});
```

## CLI Commands

The `arri` CLI provides three core workflows:

### 1. Local Development

Start your server in hot-reload mode. The CLI will watch your server files, reload them instantly, detect any API definition changes, and regenerate all registered client files.

```bash
npx arri dev
```

### 2. Manual Codegen

If you just want to run the code generators once against a static definition file, run `codegen`. This is ideal for CI/CD pipelines.

```bash
npx arri codegen ./AppDefinition.ts
```

### 3. Build for Production

Compile your server and output a optimized static build alongside your client libraries.

```bash
npx arri build
```

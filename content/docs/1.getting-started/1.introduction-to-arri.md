**Arri RPC** is a modern, code-first RPC (Remote Procedure Call) framework. It enables you to write your API endpoints and validation schemas directly in standard server-side code (like TypeScript, Go, or Rust), and instantly generate production-ready, fully type-safe client libraries for all your frontend and mobile languages.

By serving as a middleman between your backend server and your client applications, Arri eliminates the need to manually write HTTP clients, API types, or validation logic.

---

## The Philosophy of Arri RPC

Modern API development often feels fragmented. Developers typically choose between three paradigms:

1.  **Manual REST/HTTP**: Writing standard endpoints and manually writing `fetch` or `Axios` wrappers in client code. This is error-prone, time-consuming, and lacks compiler-level safety.
2.  **Schema-First (gRPC / OpenAPI)**: Writing API contracts in a domain-specific language (DSL) like `.proto` or large YAML/JSON OpenAPI schemas, then compiling them to both server stubs and clients. This adds build-step friction and forces you to learn a new language.
3.  **Monorepo-Locked (tRPC)**: Beautiful type safety, but tightly coupled to TypeScript. If you want to build a Flutter (Dart) app, a Swift iOS app, or a Kotlin Android app, you lose all benefits.

### The Arri Way

Arri RPC delivers a **code-first, multi-language** solution:

*   **Code-First**: You write regular TypeScript, Go, or Rust. No DSL files, no proto definitions.
*   **Agnostic Clients**: Your backend generates clients for **TypeScript, Dart (Flutter), Rust, Swift, and Kotlin** out-of-the-box.
*   **Runtime Validation**: Endpoints are strictly validated at the runtime edge, ensuring incorrect payloads never hit your handlers.

---

## How It Works

Arri utilizes a simple 3-step cycle to keep your client code perfectly synchronized with your backend:

```
[ 1. Server Code ] ===(Auto-Generate)===> [ 2. App Definition (JSON) ] ===(Arri CLI Codegen)===> [ 3. Safe Clients ]
```

1.  **Define Server Endpoints**: Define your types and remote procedures in TypeScript using `@arrirpc/server` or Go using `go-server`.
2.  **Generate Arri App Definition**: When you run your server in dev mode or build it, Arri automatically generates an **Arri App Definition (AAD)** file. This is a lightweight, standardized JSON specification representing all routes, input schemas, and output schemas.
3.  **Generate Clients**: The Arri CLI reads this definition and triggers the registered client generators to emit fully type-safe clients directly into your frontend/mobile repositories.

---

## Key Features

*   🚀 **Instant Codegen**: Generate type-safe clients in milliseconds during local development.
*   🔒 **End-to-End Type Safety**: Server-side validation models match client-side model types exactly.
*   📡 **Server-Sent Events (SSE)**: Full first-class streaming support across all supported clients.
*   📈 **High Performance**: Built on top of compiled JSON Type Definition (JTD) schemas for ultra-fast serialization and deserialization.

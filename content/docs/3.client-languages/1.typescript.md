title: TypeScript Client
description: Generated TypeScript/JavaScript clients for standard web browsers, Node.js, and React Native.
---

TypeScript clients are automatically generated using `@arrirpc/server` schemas. They feature robust, promise-based HTTP client classes, and full TypeScript intelligence (auto-complete and compile-time verification).

---

## Configuration

Add the TypeScript client generator to your `arri.config.ts`:

```typescript
import { defineConfig, generators } from 'arri';

export default defineConfig({
    entry: './src/index.ts',
    generators: [
        generators.typescriptClient({
            clientName: 'MyApiClient',
            outputFile: './clients/ts/client.ts',
        }),
    ],
});
```

---

## Usage

Instantiate your client and call procedures directly. Input structures are fully typed, and return models are fully checked:

```typescript
import { MyApiClient } from './clients/ts/client';

const api = new MyApiClient({
    baseUrl: 'https://api.myproject.com',
    headers: () => ({
        'Authorization': `Bearer ${localStorage.getItem('token')}`,
    }),
});

async function run() {
    try {
        const response = await api.getUser({ userId: 'user_99' });
        console.log(`Welcome back, ${response.name}!`);
    } catch (error) {
        console.error('API call failed: ', error);
    }
}
```

## Server-Sent Events (SSE) Streaming

For endpoints with streaming transport, Arri generates specialized methods that accept input params alongside standard event listeners for data, error, and connection closure:

```typescript
const stream = api.watchMessages(
    { channelId: 'general' },
    {
        onData(message) {
            console.log(`New message: ${message.text} from ${message.sender}`);
        },
        onError(error) {
            console.error('Stream error:', error);
        },
        onClose() {
            console.log('Stream closed.');
        }
    }
);

// To manually disconnect later:
stream.close();
```

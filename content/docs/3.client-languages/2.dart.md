Dart clients are perfect for mobile, desktop, and web development using Flutter. The client generator creates clean Dart classes with built-in JSON serializations.

---

## Configuration

Add the Dart client generator to your `arri.config.ts`:

```typescript
import { defineConfig, generators } from 'arri';

export default defineConfig({
    entry: './src/index.ts',
    generators: [
        generators.dartClient({
            clientName: 'MyApiClient',
            outputFile: '../mobile_app/lib/generated_client.dart',
        }),
    ],
});
```

---

## Usage

Initialize your client and call RPCs. Inputs and outputs map directly to immutable Dart classes with modern value equality support.

```dart
import 'package:mobile_app/generated_client.dart';

void main() async {
  final api = MyApiClient(
    baseUrl: 'https://api.myproject.com',
    headers: () async {
      return {
        'Authorization': 'Bearer <token>',
      };
    },
  );

  try {
    final response = await api.getUser(GetUserParams(userId: 'user_456'));
    print('Hello, ${response.name}');
  } catch (e) {
    print('API request failed: $e');
  }
}
```

## Streaming support (Streams)

In Dart, Server-Sent Events (SSE) map natively to Dart `Stream` objects, which integrate beautifully with Flutter's `StreamBuilder` widgets!

```dart
// Stream messages
final Stream<MessagePayload> messageStream = api.watchMessages(
  WatchMessagesParams(channelId: 'announcements')
);

// Listen to stream
final subscription = messageStream.listen(
  (message) {
    print('New message: ${message.text}');
  },
  onError: (error) {
    print('Stream error: $error');
  },
  onDone: () {
    print('Stream complete.');
  }
);

// To close stream subscription:
await subscription.cancel();
```
